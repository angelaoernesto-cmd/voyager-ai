# 🌍 Voyager AI — Travel Planner

Planificador de viajes con inteligencia artificial. Crea itinerarios completos con calendario visual, mapas, presupuesto, traslados y más.

## Características
- 📅 Calendario visual con días coloreados por destino
- ✦ Sugerencias de ciudades y rutas con IA (Claude)
- 🗺 Mapa interactivo de la ruta
- 📄 Exportar a PDF
- ✈ Traslados con icono en el calendario
- ◈ Presupuesto y gastos
- 🔗 Compartir viaje con código de 6 dígitos
- 🌙 Modo día / noche
- 📱 Instalable en Android e iPhone (PWA)
- ✈ Estado de vuelos en tiempo real

## Instalación rápida

Lee `GUIA-INSTALACION-ANDROID.md` para instrucciones completas paso a paso.

## Tecnologías
- React 18 + Create React App
- Anthropic Claude API
- Leaflet / OpenStreetMap
- Firebase Realtime Database (opcional)
- AviationStack API (opcional)
- PWA (Service Worker + Web App Manifest)
